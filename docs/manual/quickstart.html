Before you start

  • Use Chrome or Edge (Safari on iPhone and iPad). Install it from Downloads & help: Android, Windows and Mac have an Install DegluTech button; on iPhone, Safari → Share → Add to Home Screen. It then opens offline.
  • Records stay in this browser on this device. Export a backup daily from Settings → Backup and data; clearing browser data deletes records.
  • Use study IDs for research records and tick Hide patient names and hospital IDs on printouts.
  • For teaching, Settings → Load demo patients adds eight fictitious charts.

1 · Settings

  1. Clinic or institute: name, department, address, phone, email, logo. They print on every report.
  2. Add clinician: name, qualification, designation, RCI number, signature image → Save clinician. Pick the default signer.

2 · Add a patient

  1. Patients → Add patient: at least one of name, hospital ID / UHID or study ID; age, sex, care phase.
  2. Add and open chart. The chart opens at 2. Demographics and Referral.

3 · Chart the sections

  1. Work through the groups in the sidebar: Triage, Intake, Assessment, Synthesis, Plan. Next moves on; Ctrl K jumps to any section.
  2. Each block shows n/n recorded; the ring shows chart completion. Entries save automatically.
  3. Grades (CTCAE, DIGEST, ICF qualifiers, severity) are clinician-assigned. Record instrument versions and recording conditions.

4 · Read reports and photos

  1. Files and reports (or Fill this section from a report in any section). Set Text in photos (English, + ಕನ್ನಡ, + हिन्दी).
  2. Drop a typed PDF, a photo of a report or a Praat text export. Videos are kept for viewing only.
  3. Check every value against its source line. New values are ticked; values that differ from the chart are not. Add ticked values to the chart.

5 · Clinical tool suite

  1. Open Clinical tool suite → EAT-10; Clinician entry or Hand to patient; score items 0–4.
  2. Save to patient timeline. ≥ 3 abnormal; > 15 higher aspiration risk: consider VFSS/FEES. Report / PDF (one page), EMR note (SOAP), Handout (patient).

6 · Prescribe exercises

  1. In 4. Treatment and Toxicity record fistula and flap/wound status (No), Exercise clearance Cleared, and the clearing clinician with restrictions.
  2. In 11. Exercise Prescription pick exercises; demonstrate with the 3D patient (front, side, inside view; woman or man; drag to turn).
  3. Choose the patient's language; set Sessions per day and the dose for each exercise; record the stop and contact plan.
  4. Confirm review and release. If it is greyed out, the status line names what is missing. Then Print home programme handout (patient's language, dose, stop plan). 12. Patient Portal shows the patient view and the session log (CSV).

7 · Report

  1. 13. Summary and Report: check the readiness grid (green = filled, amber = in progress; click a tile to go there).
  2. Write the SLP diagnosis, severity, recommendations and follow-up; choose the signing clinician.
  3. Export diagnostic report → print dialog → Save as PDF. Standard SLP report, A4, black-and-white safe, patient ID and page numbers on every page. Sign according to your institution's procedure.
  4. Copy EMR note pastes a SOAP summary into the hospital record.
